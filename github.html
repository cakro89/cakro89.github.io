Tutorial Update Proyek ke GitHub

Gunakan urutan perintah di bawah ini setiap kali Anda selesai mengedit file di folder proyek Anda.

1. Tambahkan semua file yang berubah
git add .
Klik kode untuk salin
2. Berikan pesan perubahan (Commit)
git commit -m "update fitur terbaru"
Klik kode untuk salin
3. Kirim ke GitHub (Push)
git push -u origin main
Klik kode untuk salin
Tips: Jika Anda malas mengetik berulang kali, buatlah file bernama push.bat di folder proyek Anda, lalu isi dengan kode berikut: 
git add .
git commit -m "update"
git push -u origin main
