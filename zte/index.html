Cheat Sheet Perintah ZTE OLT C320

1. Cek Detail Konfigurasi Interface

show run interface gpon-onu_1/2/5:4

2. Cek Status Interface ONT

show gpon onu state gpon-olt_1/2/5 4

3. Cek Nilai Optik (Power)

show pon power attenuation gpon-onu_1/2/5:4

4. Cek Utilisasi Bandwidth Real Time

show interface gpon-onu_1/2/5:4

5. Cek Uptime & History ONT

show gpon onu detail-info gpon-onu_1/2/5:5

6. Cek MAC Address Terkoneksi

show mac gpon onu gpon-onu_1/2/5:5

7. Cek Versi Firmware ONT

show gpon remote-onu equip gpon-onu_1/2/5:5

8. Cek Status Port Ethernet ONT

show gpon remote-onu interface eth gpon-onu_1/2/5:5

9. Reboot/Restart ONT

config t
pon-onu-mng gpon-onu_1/2/5:5
reboot

10. Lock/Shutdown Port Ethernet

config t
pon-onu-mng gpon-onu_1/2/5:5
interface eth eth_0/1 state lock

11. Manajemen Hardware OLT (Info Board, Suhu, CPU)

show card
show temperature
show processor
show card slotno 12
Tips: Gunakan tanda tanya ? di akhir perintah untuk melihat opsi bantuan di terminal OLT.
